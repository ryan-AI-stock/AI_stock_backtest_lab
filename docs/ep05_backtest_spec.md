# EP05 回測規格草案

## 目前階段判斷

本任務跨 S1 / S2 / S3：

- S1：影片痛點與研究問題定義
- S2：Codex 回測工程、資料處理、輸出資料包
- S3：把結果轉成觀眾看得懂的影片內容

本 repo 先承接 S2，並把 S1 / S3 需要 ChatGPT 中控確認的地方標出。

## Repo 決策

本回測應新開 `AI_stock_backtest_lab`，不直接塞入：

- `AI_stock_market_daily`
- `AI_stock_rotation_radar`

原因：

- 每日報告 repo 需要穩定排程，不適合放大型歷史回測、參數搜尋與影片素材輸出。
- 題材輪動雷達可作為未來資料來源，但 EP05 第一版不納入題材股。
- 多標的輪動、交易成本、股利、除權息與影片資料包會形成獨立回測引擎，未來可延伸到其他個股輪動。

## 回答使用者疑問

### 為什麼先前提到日月光、富邦金、國泰金？

那是以「0050 成分股 / 台股大型股代表性」來粗抓候選池，不是說它們一定比你列的七檔更適合 EP05。

你的理解沒有錯。若本集是延續 `AI_stock_market_daily` 既有七大中大型權值股，應該以該工具既有追蹤清單為準：

- 台積電
- 聯發科
- 台達電
- 鴻海
- 廣達
- 緯創
- 緯穎

日月光、富邦金、國泰金可留到後續擴大到 0050 前二十大成分股時再納入，不放進 EP05 第一版。

### 除權息難度是什麼？

難度不在於「除權息前一天是不是通常最高」，這件事不能當成固定規則。

真正難度是資料與成交邏輯：

- 技術指標若用原始價格，除權息當天價格跳低會被誤判成大跌。
- 交易模擬若用調整後價格，會產生不存在的成交價。
- 現金股利需要在發放日進入現金，再投入後續交易。
- 股票股利或分割需要調整股數，否則資產價值會失真。

因此正式規則應是：

- 指標與報酬統計使用調整後價格。
- 實際交易成交使用原始開盤 / 收盤價。
- 現金股利在入帳日進現金，不預先假設除息前一定賣出。
- 只有策略訊號要求換股時才交易，不為了除權息事件硬做隔日賣買。

## 初始建倉規則

初始建倉分成對照組與策略組，兩者規則不同。

對照組：

- 0050 買進持有組在 2024-01-02 開盤買進 0050。
- 0050 正二買進持有組在 2024-01-02 開盤買進 0050 正二。
- 對照組只用來當績效比較線，不參與策略選股。

策略組 / 參考組 / 實驗組：

- 2024-01-02 第一筆買進就必須套用策略選股。
- 不預設先買 0050、0050 正二或任何固定標的。

這代表：

- 策略組合的第一筆持股可能是 0050、台積電、緯穎或清單內任一標的。
- 只有對照組綁定 0050 或 0050 正二；其他參考與實驗組不得沿用這個綁定規則。
- 策略不得使用 2024-01-02 收盤後才知道的資料來決定 2024-01-02 開盤買什麼。
- 回測程式需抓取起始日前的暖身資料，用前一個可用交易日收盤資訊產生第一筆建倉訊號。
- 若某策略需要 60 日動能，資料層至少要抓足 60 個交易日以上的暖身區間；初版建議抓 120 個日曆日以上。

實作上可視為：

1. 先讀取 `warmup_start_date` 到 2024-01-02 之前的歷史資料。`warmup_start_date` 不是回測起日，只是讓 2024-01-02 第一筆策略建倉有足夠的 63 / 126 交易日動能、126 日趨勢與 20 日波動資料可計算。
2. 用 2023 年最後一個可用交易日的收盤資料計算策略分數。
3. 在 2024-01-02 開盤用 100 萬資金買進策略選出的標的。
4. 之後每個交易日維持 T 日收盤產生訊號、T+1 開盤成交。

績效統計、資產曲線與交易區間仍以 2024-01-02 到 2026-05-26 為準，不把 2023 年暖身資料列入報酬率。

## 成本模型

初版採保守、可解釋設定：

- 券商手續費：買賣各 0.1425%
- 手續費最低：每筆 20 元
- 股票賣出證交稅：0.3%
- ETF 賣出證交稅：0.1%
- 不納入融資融券、借券、滑價、當沖稅率優惠

券商電子下單折扣可做成參數，但影片主結果先用未折扣的標準費率，避免被質疑過度美化結果。

## 三個策略版本

### 1. relative_strength_top1

目的：回答「每天只挑最強那一檔，能不能打敗 0050 正二？」

規則：

- 每日收盤後計算 20 日與 60 日相對強弱。
- 分數最高者成為候選持股。
- 第一筆建倉也使用同一套分數，不固定從 0050 起跑。
- 若候選分數未超過現有持股一定門檻，不換股。
- T+1 開盤換股。
- 單日最多兩筆交易：賣出舊標的、買進新標的。

優點：觀眾容易懂，結果有衝突感。

風險：可能過度追高，尤其 0050 正二在多頭期間很難打敗。

### 2. risk_adjusted_top2

目的：降低單檔追高誤判，測試「強勢但不要梭哈」是否更穩。

規則：

- 分數 = 中期動能 - 回撤懲罰 - 波動懲罰。
- 主動部位配置前兩名。
- 保留 10% 基本倉位在 0050。
- 若候選標的波動過高或回撤惡化，降低其權重。

優點：較像真人可執行的輪動。

風險：若行情集中在單一飆股，分散會輸給 top1。

### 3. regime_anchor_rotation

目的：測試「大盤不對時少做，比硬輪動更好嗎？」

規則：

- 用 0050 趨勢、加權指數或既有 daily 市場訊號判斷市場風險。
- 市場強：使用相對強弱輪動。
- 市場弱：只保留 10% 0050 基本倉位，其餘現金。
- 不使用 0050 正二作為防守資產。

優點：對最大回撤較友善，也符合 AI 輔助風險觀察定位。

風險：2024-2026 偏多頭，太早降倉可能輸給 0050 正二。

## 驗收標準

工程驗收：

- 能重現 2024-01-02 到 2026-05-26 的回測。
- 對照組 2024-01-02 初始建倉固定買自己的對照標的：0050 或 0050 正二。
- 策略組 2024-01-02 初始建倉由策略自行選股，不能硬寫成買 0050 或 0050 正二。
- 成交使用 T+1，避免偷看未來。
- 成本、股利、除權息邏輯可追溯。
- 所有交易輸出 trade log。
- 同一套策略可跑 A / B 兩組標的。

影片資料驗收：

- 能清楚回答是否打敗 0050 正二。
- 能列出輸在哪裡、贏在哪裡、代價是什麼。
- 有每日資產曲線、回撤、交易點、策略比較圖。
- `video_summary.json` 可直接被 ChatGPT 中控引用。
